# Paper Drafts

This directory is intentionally reset. Generated PDFs, auxiliary files, logs,
tables of contents, arXiv submission notes, and the old LaTeX drafts have been
removed.

The authoritative development surface is the code and markdown in the repository:

- `DERIVATION_LEDGER.md` for claim status;
- `PUBLIC_CLAIMS.md` for public wording;
- `foundations/` for theorem notes and gate writeups;
- `compute/audit.py` for executable validation.

Future papers should start from those sources, not from generated PDFs or stale
submission plans. A viable paper should have one theorem-level core and a clearly
separate `Open Bridges` section.
